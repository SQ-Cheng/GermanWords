# Android 布局、进度与双端主题验证

设备：小米 14（52ec00da），Android 16；测试调用应用的文字缩放路径，不改变手机的全局字号。

## 单屏布局

- 真机通过 100%、130%、150%、200% 字号下卡片与底栏位于一屏内的断言，并检查当前内置词条无需卡片内部滚动。
- 真机通过 320dp 窄屏、横屏、列表自测、实际触摸滑动翻页、原生音频与导入回归。
- 卡片星标、发音以及列表圆形按钮在以上各字号下均验证等宽等高；普通字号和 200% 字号截图已检查。
- 保留原有学习模式与按钮文案，移除独立翻页按钮；超长词条或例句允许卡片内部滚动，避免截断。
- Node 学习引擎与解析器回归通过。测试入口迁入 `tests/`；设备测试仍使用标准 `src/androidTest/`，不会进入主 APK。截图从测试临时缓存取回 `artifacts/`，不提交 Git。

## 拖动进度

- 使用原生 `input[type=range]`，44px 触摸区域与圆形滑块；不实现自定义指针捕获或拖动框架。
- 真机实际触摸拖动通过：松手后跳到目标范围并写入每词表进度；原有字号、圆形按钮和单屏布局测试仍通过。
- Node 测试覆盖拖动预览不改变词条、取消待播放音频、提交位置与保存进度、越界限制、跳转隐藏答案、列表定位、空列表禁用。

## 双端主题与最终回归

- `shared/theme.js` 负责偏好保存、系统跟随与主题切换，`shared/theme.css` 负责公共配色；共享层不调用 Android。Android 平台适配位于 `mobile.js` 与 Java 宿主。
- 默认自动，侧栏可选跟随系统、昼间、夜间。Node 覆盖系统变化、手动覆盖、Android 系统覆盖、重载、无效偏好和存储受限。
- Windows 源码页面与独立发布目录均在 Edge 中通过主题切换、系统跟随、手动覆盖、重载保存、实际深色侧栏检查，以及词库、卡片、星标、列表、键盘和录音回归。
- 小米真机通过昼夜与自动模式、原生系统栏图标、配置变化后的主题同步；此前全部字体、圆形控件、滑动和进度拖动、音频、导入、横屏测试仍通过。只模拟应用收到的系统主题状态，不改变手机全局昼夜设置；测试后恢复原有主题和学习设置。
- Debug、Release、测试 APK 构建与 lint 通过。两种主 APK 均逐字节检查全部 467 个资源和三份公共脚本/样式，确认不包含测试脚本或 Playwright。
- 浏览器开发依赖和锁文件仅在 `tests/`，主程序不增加运行时依赖、拖动框架、主题框架或通用状态管理层。

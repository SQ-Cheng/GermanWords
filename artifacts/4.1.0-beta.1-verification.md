# 4.1.0-beta.1 合并审查与发布验证

日期：2026-10-17。审查起点为 `codex/issue-improvements`；Android / Windows 版本均为 4.1.0-beta.1，Android versionCode 5。

## 架构结论

适合合并并发布 Beta，当前审查和验证范围内未发现剩余阻塞问题。维护边界见 [架构说明](../docs/architecture.md)。

- 录音索引/匹配和星标存储各保留一份共享实现，删除客户端副本。共享数据层不调用 DOM、播放器或 Android；语速偏好不再绑定页面控件。
- Windows HTML、CSS、JS 分离；Android 保持标准 Gradle 项目和宿主/界面适配层。两端独立的渲染、播放器与进度职责不引入统一控制器。
- 保留旧星标键、单单元词条 ID、Android 偏好键和包名。混合词条按单元区分身份，原单元星标与录音优先级不串用；无结果保留学习位置，过期/失败读取不覆盖当前状态。
- Windows 和 Gradle 自动复制公共脚本/样式，无手工源文件副本、运行时 npm 依赖、服务或新框架。测试、构建工具和主程序分目录，设备测试组件不进入主 APK。

## 发现并修复

- Windows 列表自测直接显示答案：改为独立逐条揭晓，隐藏例句/答案颜色；星标操作不揭晓，音频只在德语可见时出现。
- Windows 切换模式、隐藏答案、替换词库可能残留旧音频或排队播放：取消旧任务并清空替换前的学习状态；同词星标重绘不再丢失待播放任务。
- Windows 空搜索恢复后中文与元数据仍不可见：明确恢复可见性。
- Windows 列表操作列过窄：调整列宽和单行按钮，图标按钮保持等宽等高；键盘空格只切换一次星标。
- Android 恢复设置时筛除非法单元名；原生播放器在异步解码错误与语速切换交错时不抛出未处理的状态异常。

## 验证结果

- 六组 Node 测试通过：解析器、Android 引擎、主题、语速、词表组合/搜索、星标存储。覆盖 460 个词/录音、混合唯一 ID、原单元星标、进度/乱序恢复、非法/损坏数据、存储回退和失败/过期读取。
- Edge 对源码页面和独立发布目录回归通过：导入、混合多选、搜索/乱序/星标、双向卡片与列表自测、逐行揭晓/键盘、音频来源、普通卡片单次重播、实时倍速与保存、主题。列表截图已人工检查。
- Android Debug / Release / 测试 APK 构建及两种 lint 通过；无错误，保留已有 OldTargetApi、UnusedAttribute、SetJavaScriptEnabled 三条警告。
- 小米 14 / Android 16：架构调整后的 Debug APK 和最终签名 Release APK 均通过完整回归，包括混合多选/搜索/恢复、100%–200% 字号、320dp、圆形控件、真实滑动/拖动、主题/系统栏、原生 0.75× 播放及播放中切换 1.25×、SAF 导入和横屏；测试后恢复原设置。
- 最终 APK 的 versionName、versionCode、非 debuggable 状态及 v1/v2/v3 签名正确；所有 Android 页面文件、公共 JS/CSS 和 467 份词库资源与源码逐字节一致，无测试资产。
- Windows ZIP 无损坏，包含已测试离线目录的全部文件，包括拆出的 `app.js`、`windows.css`。APK、ZIP 和校验文件仅存放于忽略目录，不提交 Git。

## 发布边界

课本例句和软件内更新继续按要求跳过。测试设备与浏览器范围有限，不代表覆盖所有旧版 WebView 或手机。Beta 沿用历史开发证书以支持覆盖安装，正式版本仍需独立签名迁移方案。

# 更新记录

## 开发分支 · 未发布

- 双端支持多选单元混合学习，保留原单元星标与录音来源；Android 保存混合范围与进度。
- 双端支持德语/中文搜索，配合星标与乱序；搜索无结果不会抹除 Android 已保存的位置。
- 双端增加 0.75× / 1× / 1.25× / 1.5× 语速设置，自动保存并适配各端播放器。
- Windows 普通模式点击卡片重播读音；乱序可恢复，搜索和星标筛选保留当前顺序。
- 课本例句和软件内更新按要求暂缓，完整 issue 记录位于 `docs/issues-2026-10-17.md`。

## 4.0.2-beta.1 · 2026-10-17

- 双端统一发布 Beta 预发布版，Android versionCode 增至 4；提供 Android APK、Windows 离线 ZIP 和 SHA256 校验文件。
- Android 大字号下保持卡片与底部进度在一屏内，移除独立翻页按钮，保留左右滑动和键盘翻页；超长词条或例句在卡片内部滚动。
- Android 底部进度支持原生滑块拖动、位置预览及松手跳转；按乱序和星标筛选后的列表定位。
- 两端新增跟随系统、昼间、夜间主题，默认跟随系统；Android 同步系统栏颜色，圆形按钮在大字号下保持等宽等高。
- 学习模式名称保持原样，公共层仅增加主题脚本与配色；测试工具集中在 `tests/`，设备测试保留标准 `src/androidTest/`。
- 修复滚动超长卡片后，翻页到下一词仍停留在卡片中部的问题；同一词条重绘保留滚动位置。

## 4.0.1 · 2026-10-16

- Android 与 Windows 统一版本号为 4.0.1，Android versionCode 增至 3。
- 两端归入 `apps/android/` 与 `apps/windows/`，保留各端界面和平台功能。
- Excel 词库与录音统一维护在 `shared/words/`，构建时自动打包并生成 Android 资源索引。
- 两端共用 `shared/parser.js` 的 XLSX、表头和词条解析逻辑；Android 继续使用原生解压。

## 1.0.1 · 2026-10-08

- 删除顶部「德语单词」栏、标语和重复状态说明；词数放在单元标题后，词库菜单移到这一行右侧。保留操作标签、操作提示和错误反馈。
- 乱序按钮再次点击恢复原始顺序；星标筛选不打乱当前顺序，保存完整词表的乱序状态，兼容 1.0.0 进度。
- 列表支持看中文想德语、看德语想中文；逐条揭晓、隐藏答案，隐藏可能泄露答案的例句、冠词颜色和中文自测音频。
- 跟随系统字体大小；大字体改用页面滚动，按钮和词条允许换行，减少标题字号以保留学习面积。
- 修复重绘取消待播放音频、手动发音与自动发音重复、空星标视图没有同步进度，以及同名词条星标不一致。
- 修复失败或过期的异步词表读取影响当前选中状态；导入资源 URL 编码特殊字符；异常进度设置可恢复。
- 导入文件采用流式复制；文件夹中的 JSON 不再自动覆盖学习进度；备份导出临时文件可跨 Activity 重建保留。
- 移除 HTML 字符串替换生成器、重复的函数包装与加载序号；直接维护应用源文件，保留一个资源索引脚本。

# GermanWords 浏览器版

解压完整 ZIP，在 Safari、Firefox、Chrome 或 Edge 中打开 `GermanWords/index.html`。词表和录音均在包内，学习无需联网或安装运行环境；不要只打开 ZIP 内的 HTML 或单独移动它。建议使用近期版本的浏览器。

卡片两侧按钮或键盘 ← / → 翻页，Q 揭晓答案，空格切换星标；底部进度条在拖动时静音预览。支持列表、跨单元混合、搜索、语速、主题及自定义 XLSX/录音导入。修改学习模式、乱序或筛选后，操作按当前词表顺序进行。

在「词库与设置 → 课程」选择德语（1）或德语（2），加载对应的内置词表；选择会保存在当前浏览器。自定义导入显示在「我的词表（通用）」，两门课程下均可用。导入文件仅在本次页面会话中可用，新一批导入替换上一批，重开页面后需重新选择；课程切换不会清除导入文件或星标。德语（2）按所提供的 9 份词表收录，暂不含 E7/E8、例句与录音；可自行导入录音补充。

浏览器通常会保存星标、课程、主题与语速；文件路径、浏览器和隐私模式变化可能导致存储隔离或限制。重要数据请用「导出星标与设置」备份。Windows 桌面版与浏览器版可互相导入该备份；旧备份缺少课程时恢复为德语（1）。备份不含自定义词库、录音或学习位置。

「下载新版」打开发布页；更新前导出备份，解压新包后重新打开并按需导入。浏览器版不会下载或启动安装器。「意见反馈」打开 GitHub，需要联网及相应账号；应用不会在后台提交反馈。

也可以把整个目录放到普通静态 HTTP(S) 服务上，包括网站子目录；全部学习资源使用相对路径，不依赖第三方脚本。网站方式需要能访问静态服务器；需要保证断网可用时，请下载并解压离线 ZIP，不依赖浏览器缓存。

## 从源码构建

维护者在仓库根目录运行 `python tools/build-web.py`（Python 3.10+）。生成目录在 `output/web/GermanWords/`，ZIP 在同一上级目录。最终用户无需 Python。`apps/web/` 的学习界面及备份逻辑也供 Windows Tauri 使用，浏览器适配在 `browser.js`，平台能力不进入共享学习逻辑。

浏览器需支持 `DecompressionStream('deflate-raw')`、ResizeObserver 与 MP3 播放；不支持解压时会提示升级浏览器。实际浏览器引擎、平台测试范围以[发布说明](https://github.com/SQ-Cheng/GermanWords/releases)为准；引擎回归不代表已完成所有 macOS、Linux 或 iOS 设备实测。

# 浏览器版合并与发布审查

日期：2026-10-20（Asia/Shanghai）。审查基线为父分支 `codex/card-layout-feedback-copy` 的 `ea9ff34`；浏览器实现分支为 `codex/portable-web`。本次发布版本 `4.2.1-beta.3`，Android versionCode 13；客户端构建源码提交为 `d63fdea`，后续审查记录和合并提交不改变客户端代码。

## 结论与边界

未发现剩余的合并阻碍。桌面共用界面、数据规则与平台能力边界清楚，未引入业务框架、后台服务、平台控制器或重复解析器。合并目标为上述父分支；版本标签保留完整源码与审查记录。

- `apps/web/` 负责 Windows 与浏览器共用的桌面界面和备份；Android 保留手机界面。
- `shared/` 负责解析、词表组合、录音匹配、星标、主题、语速和通用展示，不访问平台安装 API。
- Windows 原生资源、更新与反馈由 `desktop.js` / Tauri 承担；浏览器适配仅解码内置 XLSX 数据并打开外链。原生配置和反馈发送器不进入浏览器包。
- `tools/frontend.py` 仅统一准备桌面构建资源，两个构建入口分别完成原生配置和浏览器 ZIP。原始词库仍只在 `shared/words/` 维护。
- 备份保留现有 Windows 格式与校验；原生更新签名、通道和安装流程兼容既有客户端。浏览器 ZIP 作为额外附件分发，不扩展安装协议。

## 审查中修正

1. 三引擎测试不再要求 Windows WebKit 的已知本地媒体故障必须出现；以后引擎修复、能够实际播放时也应通过。只允许已知平台/协议组合存在该限制，其余组合必须实际播放。
2. ZIP 校验补充逐项检查 HTML 引用的脚本与样式均包含在包内，拒绝外部依赖和逃逸包目录的路径，避免界面抽取后遗漏资源。
3. README 更新为稳定的三端介绍及 beta.3 说明，保留开发人员和致谢。更新维护文档明确原生更新与浏览器替换 ZIP 的边界；独立包内说明使用稳定的发布页链接，不重复维护版本常量。

此前实现中发现的 Firefox 轨道缺失与 WebKit 尺寸观察循环已分别用两条 CSS 和一次下一帧测量修复，没有新增平台分支学习引擎。

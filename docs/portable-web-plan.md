# 免安装浏览器版实施计划

基于 `codex/card-layout-feedback-copy` 的 `ea9ff34` 创建 `codex/portable-web`。

## 架构与取舍

- `apps/web/` 拥有 Windows 与浏览器共用的桌面学习界面、样式和备份处理；浏览器适配器只处理内置资源与外部反馈入口。
- `apps/windows/frontend/desktop.js` 继续处理 Tauri 内置资源、原生更新与反馈，不向浏览器注入原生 API。Android 保留现有手机界面与宿主。
- `shared/` 继续维护解析、词表、录音匹配、星标、主题、语速和通用展示。学习引擎不承担平台下载或安装。
- 浏览器包是完整相对路径静态目录，解压后打开 `index.html` 即可使用，也可通过普通静态 HTTP(S) 托管。无需用户启动本地服务。
- 构建时将原始 XLSX 编码为小型 JS 数据资源；浏览器用现有解析器读取，录音仍为单独 MP3 文件。避免 file:// 下 fetch 词表的跨来源限制，不复制解析规则或嵌入全部录音。
- 浏览器备份复用现有桌面格式及校验，保留 Windows 备份兼容性。浏览器限制本地存储时沿用会话回退，用户可导出备份；不同浏览器或文件路径不承诺共享存储。
- 浏览器更新为替换离线包或刷新静态站点，不引入桌面安装器、Service Worker 或服务端。反馈为打开 GitHub 意见入口，不尝试绕过上传服务的浏览器跨域限制。

## 分步实施与检查

1. 提取共用桌面界面与备份，保持 Windows 行为；运行逻辑、浏览器和迁移回归。
2. 添加浏览器资源适配和离线 ZIP 构建；验证 8 份词表、460 词、例句及录音资源完整，与原始共享文件一致。
3. 添加 Chromium、Firefox、WebKit 的 file:// 与静态 HTTP 回归：断网启动、实际播放、导入与备份、主题、自测、进度预览、字号及窄窗口；检查无外部依赖和本机路径。
4. 更新使用说明、构建说明和架构文档，验证 Windows 原生宿主与 Android 共享资源构建，提供本地开发包。

不新增业务框架、通用平台控制器、后台服务或重复词库来源。浏览器引擎测试不能替代真实 macOS Safari、Linux 桌面或 iOS 设备测试；记录实际验证边界。本次不合并、不发布、不升级已安装客户端。

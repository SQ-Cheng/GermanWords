## 实施与验证

- P2-1：发布器先执行原生 SDK / 官方 Minisign 校验；APK 公开证书指纹位于 Android 目录。真实 beta.4 APK、安装包通过；误选 beta.3 安装包被拒绝。维护端新增 Minisign 依赖，客户端不包含它。
- P2-2 / P2-7：MarkStore 增加 readAll/replaceAll，主题增加 getMode；双端使用同一份星标和偏好状态。旧 Android 备份保留主题/语速，非法字段先拒绝再改变状态。存储不可写时继续备份会话数据，并保留原有存储告警。
- P2-3：SharedPreferences 记录待授权的文件名与发布信息；临时文件逐次独立。安装前流式复核哈希与 APK 身份；关闭宿主与保存/提交安装同步，避免旧实例提交过期操作。取消、缓存缺失/损坏时清理并允许重试。
- P2-4：内置索引使用已有 loadSequence；晚到的成功/失败都不得覆盖用户导入。
- P2-5：tauri dev 禁用内置静态服务器，统一使用正式包的本地协议，避免中文资源路径与导航白名单差异；additionalWatchFolders + build.rs 调用现有 Python 准备器。真实编辑 CSS 后自动重建并生效，恢复源码后也自动生效；未保留额外同步进程。
- P2-6：沿用官方插件，通过 configure_client 限制 HTTPS、同域及最多六次请求；锁定兼容插件/reqwest 次版本，未新增下载器。
- P2-8：新增 Node 备份/初始化回归、Python 发布输入与真实 Minisign 集成测试、Rust 重定向边界测试，以及标准 androidTest 中的 UpdateChecks。

已通过：7 组 Node 测试、源码/生成前端浏览器回归、旧路径迁移备份、真实 Tauri WebView2 回归（460 词/录音、备份、重载、主题、480–1120px）、Rust test/fmt/clippy、Android Debug/测试 APK 构建与 Lint、小米 14 真机学习/布局/音频/导入及 UpdateChecks。发布工具 3 组测试使用临时测试签名，不读取生产私钥；另对既有公开包只做本地预检，没有上传。

边界：本轮没有执行真实系统安装升级，不声称覆盖所有进程回收时机或厂商安装器；待授权状态通过真实 Android 上的新管理器恢复、关闭拒绝保存、签名/损坏缓存拒绝与取消清理验证。真机测试辅助 APK 已移除；Windows 测试使用隔离 profile，结束后关闭进程。没有修改远端版本或安装包，P3 ZIP 时间戳问题仍单独保留。

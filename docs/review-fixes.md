# 合并前 P2 审查与修复

审查基线：`codex/windows-desktop-migration` / `a8d6f9c`，对照 `main` / `2ed6dc6`。本记录保存问题、最小方案与验证证据；项目介绍和最新公开版本放在根 README。

| 编号 | 问题 | 最小修复方案 | 状态 |
| --- | --- | --- | --- |
| P2-1 | 发布器直接以配置版本重命名输入产物，可能发布旧包或错误架构/签名 | 上传前验证 APK 的实际配置、系统包信息和签名；验证 Windows 安装包的签名、签名绑定版本及产物信息。所有输入验证后再上传 | 待修复 |
| P2-2 | Windows 备份绕过 MarkStore，存储回退后导出遗漏或恢复不生效 | 给现有 MarkStore 增加完整读取/替换入口，双端备份统一使用；主题通过共享模块读取当前模式 | 待修复 |
| P2-3 | Android 等待安装授权的状态仅在 Activity 内存；旧下载任务可能与新实例争用缓存 | 等待授权时保存经过校验的发布信息；返回或重启时重新校验文件再安装。每次下载使用独立临时文件，过期任务不提交安装 | 待修复 |
| P2-4 | Windows 内置词库索引异步返回后覆盖用户刚导入的词库 | 初始化也使用已有 loadSequence 判断请求是否过期 | 待修复 |
| P2-5 | Windows dev 仅复制一次资源，源码修改不会进入运行页面 | 在现有 Python 资源准备器增加轻量监听模式，由 Tauri 开发钩子运行；不增加前端框架或开发服务器 | 待修复 |
| P2-6 | Windows 仅限制初始下载 URL，默认重定向可离开指定 HTTPS 域名 | 在官方更新插件的 HTTP 客户端配置中约束重定向，与 Android 的 HTTPS/同域/次数限制一致 | 待修复 |
| P2-7 | Android 备份遗漏主题与语速 | 沿用现有 version 1 格式增加可选 theme/rate；旧备份缺少字段时保留当前设置；先验证全部字段再应用 | 待修复 |
| P2-8 | 新增更新/发布逻辑缺乏异常路径回归 | 增加发布输入错配、备份存储回退、初始化过期、Android 待安装状态/重试及重定向策略测试；不重复实现或测试官方安装框架 | 待修复 |

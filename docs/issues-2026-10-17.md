## 实现进度

- #5：已实现普通模式点击卡片重播，复用原播放入口并取消待执行的自动发音，避免重复播放。自测模式点击揭晓保持不变；Edge 源码与独立包回归验证。

- #6：两端加入 0.75× / 1× / 1.25× / 1.5×，共享保存与校验，播放器由平台负责。Node 偏好测试与 Edge 当前播放/重载测试通过；真机读取 MediaPlayer 实际参数，验证 0.75× 播放与播放中切换到 1.25×。

- #7：已实现德语/中文搜索，支持大小写、变音符号和 ß/ss；对当前学习范围筛选并与星标、乱序组合。Android 放在可滚动词库抽屉，不挤占主卡片高度；Windows 位于工具栏。无匹配项明确提示，清空恢复词表。

- #4：两端支持多选单元混合学习，保持每词的来源与唯一 ID；星标写回原单元，Android 保存混合范围、位置与完整乱序顺序。Windows 搜索/星标筛选后保留乱序，并可恢复原顺序。Node 与 Edge 通过 460 词混合、跨单元同名词星标隔离、搜索、录音来源与失败读取回归。

# 双课程词库检查与验证

日期：2026-10-20。开发分支：`codex/card-layout-feedback-copy`。本次不改变版本配置，不合并、发布或更新远端。

## 实现检查

- 德语（1）的 8 份 XLSX 和 459 份录音仅移动到 `shared/words/german1/`，内容保持原样；德语（2）的 9 份 XLSX 从用户指定目录逐字节复制到 `shared/words/german2/`，未引入原目录的旧 HTML。
- 两门课程由一个共享目录模块管理。解析、混合来源标识、录音匹配和星标仍使用已有共享模块；界面与原生导入、播放职责保持在原层级。没有新增框架、后台服务或通用控制器。
- 课程选择器及内置/导入分组共用样式。内置 E 单元按编号排序，专项词表置后；长文件名可换行，同名导入保留区分后缀。主页面显示课程，纯导入学习显示“我的词表”。
- 德语（1）沿用原星标和 Android 进度键；德语（2）使用课程前缀。导入键预留全部内置身份后统一分配，不随课程变化。
- 音频索引不随可见课程裁剪。内置词条缺少录音时仅允许用户录音补充，禁止借用另一内置课程。桌面播放不再尝试未经索引确认的原始相对路径。
- Windows 与浏览器同步建立完整内置目录，实际 XLSX 仍按需解析；既有异步序号检查拒绝过期读取。快速切换课程后，旧解析结果不能覆盖当前课程。
- Android 清空过渡界面时不保存空学习状态，切换前保存原进度。备份先验证课程字段，再替换状态；旧备份兼容德语（1）。导入的存储生命周期保持原有平台行为。
- 删除 Android 已不再使用的浏览器导入函数；正式包不包含设备测试组件、开发依赖或调试端口。

## 数据与测试边界

- 德语（2）所提供内容为 381 个词条，缺少 E7/E8、例句及录音；保留原表，不补写、不猜测。没有录音时隐藏发音入口。
- 桌面导入仍为会话内文件，重开需重新选择，新一批替换上一批；Android 导入仍由原生持久保存。课程切换不改变这一行为，两门课程下均可使用导入词表。
- 所有桌面设备测试均在当前 Windows 电脑完成，没有 macOS/Linux 实机可用，不能把 WebKit 引擎回归写成 Safari 真机验证。
- Windows Playwright WebKit 在非 ASCII 本地路径下存在已知 MP3 播放限制；已用独立音频页复现。此组合明确保留限制记录，HTTP 模式要求实际播放，Edge/Firefox 的本地离线模式也要求实际播放。
- 真实 Android 系统文件选择器的各厂商界面未自动化点击；测试通过标准内容提供器执行实际原生读取流程。旧手机和其他厂商设备未逐一实测。

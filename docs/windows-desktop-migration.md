# Windows 桌面迁移架构与审查

基线：`codex/update-source-investigation` 的 `e44bdeb`。实现分支：`codex/windows-desktop-migration`。先确定边界，再实现；不合并 main、不替换旧云盘更新入口。

本文保留当时迁移的设计与审核记录；当前桌面共用界面已移至 `apps/web/`，最新目录边界以 [结构与维护约定](architecture.md) 为准。

## 初稿

采用 Tauri 2 / WebView2，继续使用普通 HTML/CSS/JavaScript 学习界面，不引入前端框架。Windows 用 NSIS 按用户安装，保留系统窗口边框、标准缩放和关闭行为。Android 宿主、界面及学习引擎不迁移。

| 目录 | 唯一职责 |
| --- | --- |
| `shared/` | 原有学习规则、词库及双端发布版本配置 |
| `apps/windows/frontend/` | Windows 页面、样式、学习交互、薄桌面适配 |
| `apps/windows/src-tauri/` | 应用窗口、受限原生能力、官方更新插件及安装配置 |
| `tools/` | 资源准备、打包与维护发布 |
| `tests/` | 现有公共测试、浏览器学习回归及桌面适配测试 |

## 第一轮审核：功能与迁移

- 保留全部现有学习功能和公共脚本。内置词库随应用打包并自动加载；用户仍可用系统文件选择器导入词表/文件夹，导入会话的原有语义保持不变。
- 保留可直接打开的前端作为开发/旧数据导出入口；它与桌面共用同一套界面文件，不维护第二套产品。
- 外部浏览器存储和 WebView2 存储属于不同应用，不能声称自动继承。加入版本化 JSON 星标/偏好导出导入，提供从旧页面迁移的明确步骤；校验失败不得修改已有状态。
- 桌面固定应用 identifier 和 WebView2 数据位置，后续安装/更新不迁移或清空用户数据。安装包与数据分开。
- 界面逐步靠近手机：统一绿色配色、清楚的词表标题、保留原学习模式名称、整洁的工具栏和窄屏词库抽屉；保留桌面键盘与列表能力，不重写学习引擎。

## 第二轮审核：更新、安全与复杂度

- 更新来源仍是当前清华云盘；保留启动检查、每天至多一次、手动检查、用户确认和失败不影响离线学习。Windows 采用 Tauri 官方签名安装更新，不继续扩展 PowerShell ZIP 覆盖器。
- Android 和旧 Windows 的 `update-beta.json` 及 RSA 协议保持兼容。新桌面使用单独的固定 Windows 元数据文件，由同一维护发布工具生成 Tauri 原生格式；签名密钥保存在仓库外，不强行共享不同平台的安装协议。
- 下载请求保留 User-Agent、HTTPS 和缓存规避，测试云盘重定向。原生更新能力只供本地应用使用，不向外部页面开放；默认不提供通用 shell、任意文件读写或远程页面加载。
- 使用成熟安装器处理关闭应用、覆盖升级和卸载；不增加后台服务、自制安装器、差分更新、数据库、通用平台抽象或自建服务器。
- 先验证 x64 Windows 当前环境；提供 ARM64 构建配置和明确验证边界，不以交叉编译或浏览器测试冒充其他设备实测。WebView2 缺失时由安装包引导安装。
- 旧版从静态页迁移到桌面需要首次运行新安装包；现有 ZIP 更新器不会被悄悄替换为不兼容的安装格式。

## 实施与验收顺序

1. 提交此架构和两轮边界审查。
2. 实现最小桌面宿主、确定性资源准备、内置词库和迁移导入导出，提交。
3. 接入云盘与官方安装更新，打包验证，提交。
4. 调整响应布局，运行公共/浏览器和真实 WebView2 回归；验证安装、升级、数据保留与卸载，更新文档并提交。

参考：[Tauri 前置环境](https://v2.tauri.app/start/prerequisites/)、[Windows 安装器](https://v2.tauri.app/distribute/windows-installer/)、[官方更新插件](https://v2.tauri.app/plugin/updater/)。最终验证结果另行记录，计划中的项目不视为已通过。

## 实现后的复核

按上述边界完成桌面宿主、资源准备、迁移备份与响应布局。删除旧 PowerShell 更新器，兼容 ZIP 仅由同一前端生成，没有保留第二套更新实现。实际完成 beta.2 安装 → 云盘提示 → beta.3 签名安装 → 自动重启 → 数据保留 → 标准卸载；目标版本完成真实 WebView2 回归。详细证据与未验证设备见 [桌面验证记录](../artifacts/windows-desktop-verification.md)。

# 合并 main 审查

日期：2026-10-21（Asia/Shanghai）。目标 `main` / `origin/main` 基线为 `f9b9dca`；开发分支为 `codex/card-layout-feedback-copy`，本轮审查前为 `5aefd2f`。审查包含卡片布局、发音与静音预览、桌面界面抽取、浏览器发行版及双课程目录。

## 架构结论

未发现需要阻止合并的架构问题。继续采用现有分层，没有新增框架或平台控制器：

- `shared/` 维护课程及词表身份、解析、搜索、星标、录音匹配、主题与通用展示规则。录音模块不播放，目录模块不渲染或解析词表。
- `apps/web/` 是 Windows 与浏览器唯一的桌面学习界面和备份实现；两种适配器只提供资源与平台能力。浏览器包不含原生更新配置、反馈发送器或桥接代码。
- Android 保留手机交互与偏好适配，Java 处理本地资源、导入和播放器。没有为共享而抽取跨平台会话控制器。
- 内置课程按根目录隔离，德语（1）沿用原身份；德语（2）采用课程前缀。导入身份全局分配，切换课程不改变导入键与星标；内置录音禁止跨课程回退。
- Windows 和浏览器在解析前同步建立完整目录；解析结果仍由请求序号校验，过期读取不覆盖当前课程。备份新增字段保持旧格式兼容。
- 构建入口复用桌面资源准备函数；共享原件只有一份，生成目录、运行环境与测试组件不进入生产源码或正式应用。

## 发现与修复

**P2：Android 跨课程恢复备份残留旧搜索。** 恢复通过偏好切换课程并重载词库，没有经过课程选择器的搜索清理。若原课程搜索 `lernen`，随后恢复德语（2）E1 备份，就可能将全部 37 个词条筛掉，造成已恢复但没有内容的假象。

最小修复是在校验及应用备份后、重载前清空搜索字符串和输入框。新增回归经过原生 manifest 与资源读取适配，实际解析 XLSX，验证恢复后 37 个词条全部可见，并验证旧备份仍恢复德语（1）的 65 个词条。没有增加状态管理层或改变备份格式。

本次未发现其他可复现的合并阻碍。文档已核对分层、课程与导入生命周期、版本说明及已知测试边界；README 保持项目介绍，不加入本轮开发进度。
